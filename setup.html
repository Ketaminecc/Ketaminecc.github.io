Counter-Strike 2

CS2 internal — install

Loader + in-game menu

Loader plus in-game menu. Sign in once; the module updates itself.

01 · Needs

  • Windows 10/11, 64-bit.
  • Active CS2 key (a Roblox key is refused).
  • Antivirus off, or the folder excluded.
C++ redist x64

02 · Download

ZIP contains the loader, models and hitsounds. Extract it — never run it from inside the zip.

Windows x64 · ZIP

Each click issues a private link that expires after one use.

03 · Set up

  1. Extract

    Any permanent folder, e.g. Documents\ketamine.

  2. Run as administrator

    Right-click Ketaminecc.exe → Run as administrator.

  3. Sign in

    Email from your order + key from Keys.

Emailthe email on your order LicenseKET-xxxxx-xxxxx-xxxxx-xxxxx

04 · Inject

  1. Open CS2

    Through Steam. The loader can start it for you.

  2. Press Inject

    The loader maps the module and closes itself.

  3. Open the menu

    INSERT in game.

Failed?

loader.log next to the exe names the step that failed.

Roblox

Roblox external — install

External, no injector

Standalone external. Roblox stays open; the menu draws over it.

01 · Needs

  • Windows 10/11, 64-bit.
  • Active Roblox key (a CS2 key is refused).
  • Antivirus off, or the folder excluded.

02 · Download

One ZIP, no separate module.

Windows x64 · ZIP

Each click issues a private link that expires after one use.

03 · Run

  1. Extract

    Any permanent folder; keep the contents together.

  2. Open Roblox

    Join the experience and leave the window running.

  3. Run as administrator

    Sign in with your order email + key.

  4. Open the menu

    RSHIFT in the Roblox window.

Keys are per game

A Roblox key only unlocks this build.
