Install checklist

—

  1. Disable AV/Antivirus.

    Turn off real-time protection before you extract the loader. If your antivirus removes the file, restore it and add the extracted folder to your exclusions.

  2. Install C++/.NET and redistributables.

    Install the Microsoft Visual C++ Redistributable (x64) and the .NET Desktop Runtime. Both are free downloads from Microsoft.

    C++ redistributable .NET download

  3. Download loader.

    Get the latest public build and extract the zip to a permanent folder. Keep every extracted file together and do not run the loader from inside the archive.

    Download loader Windows x64 · ZIP

  4. Launch Loader — Run as administrator.

    Open the extracted folder, right-click Ketaminecc.exe, and choose Run as administrator.

  5. Enter credentials — Email, License. Hit Enter.

    Use the email on your order and paste your license key. You can copy the key from your Keys page.

    Emailthe email on your order LicenseKET-xxxxx-xxxxx-xxxxx-xxxxx

  6. Press Attach and have fun.

    Open Roblox, then press Attach in the loader. The menu opens with RSHIFT.
